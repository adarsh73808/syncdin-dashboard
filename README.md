A modern AI-powered networking dashboard built as part of the **SyncdIn Internship Assignment**. The dashboard helps users discover meaningful professional connections through AI-powered recommendations in a clean, engaging, and responsive interface.

# 📌 Project Overview

SyncdIn is an AI-first networking platform where every user has an AI Twin that understands their skills, interests, and career goals.

This project focuses on building an **AI Match Dashboard** that provides personalized networking recommendations and improves user engagement through a modern user experience.

# ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/adarsh73808/syncdin-dashboard.git
```

### Navigate into the project

```bash
cd syncdin-dashboard
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
